# ✨ Features

- 🌍 Search weather by city
- 📍 Current Location Weather
- 🌡️ Real-Time Temperature
- 🌥️ Weather Conditions
- 💧 Humidity
- 🌬️ Wind Speed
- 🌡️ Pressure
- 👀 Visibility
- 📅 5-Day Forecast
- ⏰ Hourly Forecast
- 🤖 AI Weather Insights
- 🎨 Dynamic Weather Background

---

# 🛠 Tech Stack

- Kotlin
- Android Studio
- XML
- Retrofit
- RecyclerView
- OpenWeather API
- Material Design


Open Android Studio

Sync Gradle
